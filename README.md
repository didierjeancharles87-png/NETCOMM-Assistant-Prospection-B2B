# NETCOMM – AI-Powered B2B Prospecting Assistant

## Project Overview
NETCOMM is an AI-assisted B2B prospecting automation project focused on supporting international business development for Malagasy vanilla and cocoa products.

## Objectives
- Identify potential international buyers.
- Automate web-based prospect research.
- Use AI to analyze and organize prospect information.
- Centralize prospect data for business development.

## Technology Stack
- n8n – Workflow automation
- Google Gemini – AI processing
- Groq – AI processing
- Tavily – Web search
- Google Sheets – Data storage

## Workflow Architecture
1. Prospect research through web search.
2. AI-assisted information processing.
3. Lead information organization.
4. Data storage in Google Sheets.

## Key Capabilities
- Automated web research.
- AI-assisted prospect qualification.
- Lead data management.
- Integration with Google Sheets.

## Project Status
Prototype – Under development.

## Security
Credentials and API keys must be configured separately in n8n.
No credentials should be published in this repository.
